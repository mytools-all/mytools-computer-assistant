# 电脑助手

版本 0.1.1，独立 MyTools 插件。依赖公开 system.resources 能力，需配合本次更新的主程序。旧宿主会明确降级到原始进程排行并提示更新。

展示 CPU、物理内存、交换/页面文件、逐网卡上传下载、磁盘余量、进程 CPU/内存前 20、硬件与系统信息。最近一分钟曲线只保存在当前会话中，不保存进程历史或上传信息。GPU 和温度首版不支持。

默认每秒刷新，可改为 2/5 秒。仅打开且可见时监控；隐藏、关闭或手动暂停后停止采样。首次或长时间暂停后的 CPU/网速需要第二次采样才能显示。所有调用走公开能力，不直调 Tauri、不依赖其他插件或宿主源码。

资源提醒默认关闭。用户开启后连续 3 次达到阈值才提醒；系统通知最多每 5 分钟一次，通知失败仍在页面显示。不结束进程、不清理或删除文件，不在关闭插件后后台监控。

资源排行默认按应用汇总，可展开全部关联 PID，或切换按进程查看；可搜索名称/PID，按 CPU 或所选内存口径排序。同一路径程序的父子进程合并，独立实例和不同安装路径保持分开；同一服务程序的客户端经 Windows 服务配置核实后合并。因此应用分组是可解释的近似，不保证完全复现 Windows 任务管理器的分组。

内存默认使用私有工作集，接近任务管理器常用内存列，另可选择包含共享部分的工作集。后者合计可能重复计算共享页。私有工作集来自 Windows 原生 PROCESS_MEMORY_COUNTERS_EX2.PrivateWorkingSetSize，不使用私有提交量冒充；受保护进程或不支持该接口的旧系统显示不可用，部分可读的应用显示已知下限和覆盖数量，排序也按该下限。整机内存卡片仍表示系统整体物理内存使用量，不等于进程列之和。

CPU 统一按整机 0—100% 显示。网络按单个网卡展示，避免 VPN/虚拟网卡累计产生重复流量。磁盘容量数据可能有短暂缓存，不表示硬盘实时读写速度。

开发：npm install --ignore-scripts、npm test、npm pack。通过 MyTools 开发者页面安装 tgz。源目录与安装目录独立，修改后需重新安装。通过 npm 安装 @mytools-all/mytools-computer-assistant@0.1.1。插件遵循 MIT LICENSE。

## MyTools 兼容范围

版本 0.1.2 声明支持 MyTools >=0.2.0 <0.3.0（0.2.x 稳定版），插件 API 为 v1。主程序超出范围时应更新插件或使用受支持的主程序版本。旧版主程序可能不识别此声明，请先升级到提供兼容检查的 MyTools。
